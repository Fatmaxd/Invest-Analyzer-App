## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Git push workflow

After making changes locally, run these commands to save and push updates to GitHub:

1. Stage all changes:

```
git add -A
```

2. Commit with a short message:

```
git commit -m "Describe your change here"
```

3. Pull latest remote changes (recommended) and push:

```
git pull --rebase origin main
git push origin main
```

If you prefer working on a branch:

```
git checkout -b my-feature
git push -u origin my-feature
```

If you have authentication issues, set up SSH keys or use a personal access token for HTTPS pushes. See GitHub docs for details.
